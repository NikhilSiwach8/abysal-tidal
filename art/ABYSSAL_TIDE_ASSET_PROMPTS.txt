 ABYSSAL TIDE — ASSET GENERATION PROMPTS (copy-paste ready)
=====================================================================

What this file is
-----------------
Image and animation prompts for every visual asset in Abyssal Tide, written to
reproduce the *look* of the reference recording (ink-wash anime illustration,
grey fog, one hot accent colour, dry-brush lettering, parallax idle animation)
applied to OUR original theme: a hooded harpooner hunting the Leviathan, a sea
serpent, in a sunken deep-sea world.

Do not add the reference game's name, logo, characters, symbols or studio name
to any prompt, and do not upload its screenshots as image references. Use your
own generated "style anchor" (prompt 0.1) as the only reference image. That keeps
every asset original and consistent with each other.

Every prompt below is self-contained: it already includes the shared style
block, so you can paste any single prompt into an image generator as-is.
Works with Midjourney, GPT-Image / DALL-E, Flux, Ideogram, Leonardo, SDXL.
"Settings:" lines tell you aspect ratio and background handling.


---------------------------------------------------------------------
 HOW TO KEEP THE ART CONSISTENT (read once)
---------------------------------------------------------------------
1. Generate prompt 0.1 (STYLE ANCHOR) first. Pick the best result.
2. Use that image as the style reference for EVERY other asset:
     Midjourney:  add  --sref <anchor-image-url> --sw 200
     GPT-Image / Ideogram / Leonardo / Flux: attach the anchor as a style
     reference image and keep the text prompt unchanged.
3. Generate the hero and the Leviathan reference sheets (2.1, 3.1) next and use
   them as character references (Midjourney: --cref <url> --cw 100) for every
   pose, animation frame and symbol that shows those characters.
4. Keep one seed per asset family (Midjourney --seed, Flux/SDXL seed field).
5. Never change the palette hex codes, light direction (soft top-left), or
   line weight wording between prompts.
6. For symbols: generate the EMPTY TILE (4.0) once and composite each symbol
   (generated isolated) onto it in code/Photoshop. Identical frames = consistent grid.

Palette (use these exact values everywhere)
   Ink black        #171B1D     Ink grey        #222A2D
   Fog paper        #DCDFD7     Fog paper dark  #C9CEC6
   Abyss teal       #2BB3A3     Teal glow       #5FE3D2
   Ember coral      #E8553E     Gold            #FFD36B
   Abyssal purple   #A26FF0     Highlight white #F3F5F2
Rule: every image is 90% greyscale ink + fog. Colour appears ONLY as small
accents: teal (hero, Wild, magic), ember coral (embers, coral fronds, danger,
high symbol panels), gold (treasure, big wins), purple (Abyssal tier only).

Fonts (to match the brush/UI look; all open-licence, bundle with @fontsource)
   Logo & big titles:  generated as images (prompts 6.x) — dry-brush lettering
   Headings/buttons:   "Permanent Marker"   (fallback "Rock Salt")
   Numbers/labels:     "Lilita One"         (heavy, rounded, like the reference UI)
   Body/rules text:    "Outfit" 400/600/800
   UI label colour on dark bar: teal #5FE3D2; values: white #F3F5F2.
